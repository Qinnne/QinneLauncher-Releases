# Qinne Launcher

### A Custom Launcher for Hyundai & Kia Android Infotainment Systems

Qinne Launcher (QL) is designed primarily for the 7th-generation Hyundai Elantra, 10th-generation Hyundai Sonata, 3rd-generation Kia K5, and other vehicles with compatible infotainment systems.

**Core Features:**

- **No-Root Key Mapping:** Enables physical head-unit buttons to control third-party media players.
- **Dedicated Audio Service:** Provides audio-system adaptations for supported head units.
- **Dynamic Wallpaper Service:** Supports video wallpapers and service recovery after launcher restarts.
- **Windows 11-Inspired Design:** Brings a modern Windows 11-inspired desktop experience to automotive displays.

QL aims to extend the capabilities of compatible factory infotainment systems without requiring root access.
