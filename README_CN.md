# Qinne Launcher

### 专为现代、起亚原厂 Android 车机打造的第三方桌面

Qinne Launcher（QL）重点适配现代第七代伊兰特、第十代索纳塔、第三代起亚 K5，以及采用相同或兼容车机系统的车型。

**核心能力**

- **无 Root 按键映射：** 适配原厂车机物理按键，实现第三方播放器控制。
- **专用音频服务：** 针对目标车机音频运行环境提供适配方案。
- **动态壁纸服务：** 提供视频壁纸运行及重启后的恢复机制。
- **Windows 11 风格桌面：** 参考 Windows 11 的视觉设计与交互理念，打造专属车机桌面。

QL 致力于在不 Root 原厂车机的前提下，拓展车机能力，提供更自由的第三方应用与桌面体验。
